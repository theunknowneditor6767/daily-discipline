# DailyDiscipline — personal routine app (iPhone, add-to-home-screen PWA)
Wake anchor, wind-down, training, abs and eating on one calm screen. Must look premium and motivate without nagging.
This repo is PUBLIC. Never commit names, personal habits, local file paths or private notes; the owner's private context lives outside the repo.
Rules: data stays on the device (IndexedDB + export); no third-party analytics; push stays behind `settings.pushEnabled`.
Workflow: spec in docs/superpowers/specs/, state in plan/ (features.json + PROGRESS.md), test-first, `npm run verify` must pass before every commit. Pages deploys from main via .github/workflows/pages.yml.
